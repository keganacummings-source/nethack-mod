Basic SFX pack (procedural)
===========================
Place the entire "sounds/" folder next to NetHackW.exe.
Config: SOUNDDIR=sounds + SOUND=MESG lines in nethackrc.template

Included:
  hit, miss, kill, death
  door_open, door_close, door_crash, door_resist, lock
  trap, fall, zap, fizzle, fire, cold
  levelup, lucky, hungry, eat, pickup, drop, sit
  thud, wham, metal, ambient

These are simple generated tones/noise — replace any file with your own
WAV of the same name to customize.
